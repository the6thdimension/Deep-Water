# RH Scene Manager

A powerful scene management tool for Unity projects, designed to enhance workflow efficiency and organization.

## Features

### Quick Scene Access
- **Scene Groups**: Organize scenes into logical groups for better project organization
- **Recent Scenes**: Quickly access recently opened scenes
- **Favorites**: Mark frequently used scenes as favorites for easy access
- **Search**: Find scenes quickly with the built-in search functionality

### Scene Macros
- **Create Macros**: Define sequences of scenes to load together
- **Keyboard Shortcuts**: Assign keyboard shortcuts to macros for rapid scene switching
- **Custom Actions**: Add custom actions to be executed when running macros

### Scene Validation
- **Missing Assets**: Check for missing assets in scenes
- **Lighting Data**: Validate lighting data in scenes
- **Performance Metrics**: Get insights into scene performance

### User Preferences
- **Customizable UI**: Configure the Scene Manager UI to your liking
- **Behavior Settings**: Adjust how the Scene Manager behaves
- **Import/Export**: Share your Scene Manager settings with team members

## Getting Started

1. Open the Scene Manager window from the menu: **Window > REALMHAUS > Scene Manager**
2. Use the tabs to navigate between different features:
   - **Scenes**: Manage scene groups and individual scenes
   - **Recent**: Access recently opened scenes
   - **Macros**: Create and manage scene macros
   - **Settings**: Configure the Scene Manager

## Usage Tips

- **Drag and Drop**: Drag scenes from the Project window into scene groups
- **Right-Click**: Right-click on scenes for additional options
- **Thumbnails**: Scene thumbnails are automatically generated when available
- **Tags**: Add tags to scenes for better organization and filtering

## Requirements

- Unity 2019.4 or higher
- .NET 4.x Scripting Runtime
