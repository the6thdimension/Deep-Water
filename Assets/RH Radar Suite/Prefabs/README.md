# RH Radar Suite Prefabs

This folder contains ready-to-use prefabs for the RH Radar Suite.

## Available Prefabs

### RadarSystem

A complete radar system with all LOD modules attached. Simply drag this prefab into your scene and configure the parameters as needed.

### RadarTarget

A simple target object with a RadarSignature component. Use this as a template for creating your own radar-detectable objects.

## How to Use

1. Drag the desired prefab into your scene
2. Configure the parameters in the Inspector
3. For the RadarSystem prefab, you can enable/disable specific LOD modules as needed
4. Use the RadarControlPanel (RH Navy Sims > Radar Suite > Radar Control Panel) to adjust settings at runtime

## Creating Custom Prefabs

You can create your own custom prefabs by:

1. Setting up a GameObject with the desired radar components
2. Configuring the parameters to your specifications
3. Dragging the configured GameObject into the Project window to create a prefab

This allows you to create specialized radar systems for different use cases, such as air search radars, surface search radars, or fire control radars.
